# fran3c.com

Frank / Sihan Chen's personal index: experience, projects, publications, and a photographic archive.

## Structure

- `/` — index
- `/features/` — experience
- `/projects/` — projects
- `/publications/` — publications
- `/photographs/` — selected photographs
- `/photographs/archive/` — full photographic archive

The site is static and served from `dist/`.

## Deploy to Cloudflare Pages

```sh
npx wrangler pages deploy dist --project-name fran3c
```
